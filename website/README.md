# R2K16 Documentation Site

Full codebase documentation for the R2K16 repository, built with
[Docusaurus 3](https://docusaurus.io/).

## Quick start

```bash
cd website
npm install
npm start          # dev server with hot reload (http://localhost:3000)
```

Production build & preview:

```bash
npm run build
DOCUSAURUS_BASE_URL=/ npm run serve   # serve at / instead of /R2K16/
```

`npm run build` defaults to `baseUrl: '/R2K16/'` for GitHub Pages project sites;
override with the `DOCUSAURUS_BASE_URL` environment variable when hosting at a
domain root. The dev server (`npm start`) ignores this.

## Content

All documentation lives in `docs/` as plain Markdown:

| Folder | Content |
| --- | --- |
| `docs/intro.md` | Introduction |
| `docs/getting-started/` | Prerequisites, build guides, project status |
| `docs/architecture/` | Engine internals (Instance tree, DataModel, jobs, scripting, physics, rendering, networking, serialization, terrain/CSG) |
| `docs/modules/` | Per-project reference for every top-level directory |
| `docs/development/` | CI, FastFlags, security, conventions, docs maintenance |
| `docs/reference/` | Repository map, glossary, roadmap, troubleshooting, FAQ |

Sidebars are autogenerated from the folder structure; ordering comes from
`sidebar_position` front matter and `_category_.json` files. Mermaid diagrams are
enabled. Broken links fail the build.

## Deployment

`.github/workflows/docs-deploy.yml` (repo root) builds and publishes this site to
GitHub Pages on every push to `main` touching `website/**`. Published URL:
`https://<user>.github.io/R2K16/`.

See `docs/development/docs-site.md` in the built site for the full maintenance
guide.
